I explored the repository and implemented the calibration system that uses least-squares fitting to align simulated battle submetrics with observed data. The new system introduces a `CalibratedSimulator` that wraps an existing simulator, collects statistics from simulated battles, fits scale (and optionally decay) parameters to minimize the squared error against observed averages, and adjusts future submetric outputs accordingly. The least squares fit is implemented using numpy, and the calibration flow includes handling of optional alpha exponent, dimensionality checks, and covariance-weighted scaling. I added unit tests covering the calibration fitting logic, including alpha usage and error handling. Notes: the calibration process assumes independence of measurements, so covariance handling is simplistic (using inverse variances) and the fitter currently uses mean-based fitting; future work could incorporate full covariance matrices or regularization if needed.
